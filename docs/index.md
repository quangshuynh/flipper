# Flipper

Flipper is a **local-first resale intelligence and operations tool**. It helps evaluate exported
opportunities, record what was actually acquired, track inventory, reconcile marketplace activity,
and measure recorded results without turning a marketplace account into the system of record.

The current analyzer specializes in secondhand computer listings. Inventory, sales, accounting,
reports, and the web dashboard support the broader resale workflow. Generalized deal discovery is
[planned](roadmap/deals.md), not implemented.

## The operating loop

1. Analyze a user-provided listing export.
2. Review estimates and acquire deliberately.
3. Assign a durable Q-number and track the item locally.
4. Link read-only marketplace activity where identity is exact.
5. Import sales and costs explicitly.
6. Reconcile what is known and report recorded results honestly.

Start with [installation and setup](getting-started.md), then choose a task from the Guides section.

## Boundaries

Flipper does not crawl marketplaces, mutate eBay, store raw marketplace responses, convert
currencies, or claim incomplete economics are final profit. Optional external integrations fail
independently from deterministic local paths.
