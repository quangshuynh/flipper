Analyze an exported listing

The analyzer remains the deterministic local/exported-feed workflow. Analysis alone does not create inventory or a Q-number.

python main.py

By default it reads data/listings.json, applies deterministic parsing and pricing, and uses optional AI, market data, and Discord integrations only when configured.

Record a completed acquisition

After reviewing an analysis and deciding to acquire the item, explicitly provide the actual amount paid and acquisition date:

python main.py acquire --feed data/listings.json --listing-id LISTING_ID --cost 241.37 --acquired-at 2026-09-16

Success creates one durable Q-number and attaches the selected analysis as its baseline valuation atomically. Asking price, ideal buy price, and estimated resale are estimates; none replaces actual acquisition cost.

Current boundary

Browser mutations and analyzer forms remain deferred. The web page does not crawl marketplaces, calculate valuations in the browser, or purchase anything.
